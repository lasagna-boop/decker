## Design Context

### Users
Single primary user (owner): uses an iPhone from bed ~2m away as a remote for a MacBook with lid closed, connected to an external monitor for watching shows/series. Phone and Mac on the same Wi‑Fi. Also uses the phone as a programmable macro pad (app launcher + app-specific actions) during daytime.

### Brand Personality
Calm, capable, intimate — a personal remote, not a corporate dashboard. Three words: **quiet / physical / reliable**.

### Aesthetic Direction
Dark, low-light friendly (bedroom TV ambient). VideoPlay uses warm amber; Deck uses cyan accent. Avoid purple neon AI defaults, heavy glassmorphism, and cluttered dashboard layouts. Prefer large tap targets and clear remote-like hierarchy over dense tooling.

### Design Principles
1. One job per mode: Deck = launch macros; VideoPlay = media remote.
2. Thumb-first: large controls, minimal precision required from bed.
3. Status always visible: connection and active Mac app must be obvious.
4. Fail loudly and recoverably: unreachable Mac, missing Accessibility, lost windows.
5. Progressive disclosure: advanced/app presets appear only when relevant.
